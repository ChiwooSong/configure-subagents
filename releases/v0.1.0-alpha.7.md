# 0.1.0-alpha.7 — explicit installation and update results

Prerelease date: 2026-10-19 (Asia/Seoul). npm channel: **`next`**. **1.0.0 remains on hold.**

Successful installation/update previously ended with a sentence about unverified discovery and Agent execution, which users could mistake for an error. The CLI now starts successful results with one of:

```text
SUCCESS: Skill installation completed.
SUCCESS: Skill update completed.
SUCCESS: Skill files already match this version. No changes needed.
```

The CLI version follows the banner, then existing per-host `installed:`, `updated:` or `unchanged:` paths and any backup locations. The final lines show the selected hosts' invocation commands. A mixed result (one changed host and one unchanged host) reports successful completion with both outcomes.

Failures start with `ERROR: Skill installation failed.` or `ERROR: Skill update failed.` on stderr and exit 1; invalid arguments start with `ERROR: Invalid arguments.` and exit 2. Failed operations never print a success banner. Help, version and empty invocation remain informational and do not modify files.

## Install or update

```sh
npx --yes @woody_s/configure-subagents@next install --agent all
npx --yes @woody_s/configure-subagents@next update --agent all
```

Use `install` for a new installation, `update` for existing selected hosts, and `--agent claude` or `--agent codex` for a single host. For reproducibility use `@0.1.0-alpha.7` instead of `@next`.

**Skill files are identical to alpha.6.** Updating an unmodified alpha.6 installation reports successful no-op and preserves bytes/mtimes. Old unmodified recognized payloads can still update; customized Skills still stop for manual merging. Existing `.claude/agents` files remain untouched. There is no change to backup/rollback behavior or exit codes.

## Validation and scope

- **61 Node tests** cover successful installation/update, repeated no-op, selected-host next steps, mixed host results, stderr/exit-code failures and existing preservation cases.
- **56 Python tests** and Skill structure checks remain green.
- The actual **17-file tarball** is installed offline and tested for both-host installation, alpha.5 update and no-change repeats, including success banners and existing Agent preservation.
- Exact-commit CI results and public-registry artifact verification are recorded with the GitHub release.

This is a CLI-output change; no new authenticated host/model sessions were run. Successful file copying does not prove host discovery, model access or generated-Agent runtime behavior. The [Claude analysis/cross-review limitation](../README.md#known-behavior-limitation-in-alpha5) and [1.0.0 checklist](../docs/V1_RELEASE_CHECKLIST.md) remain unchanged. This release updates `next` only; `latest` remains the older alpha.2.
