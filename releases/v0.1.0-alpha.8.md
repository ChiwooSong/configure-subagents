# 0.1.0-alpha.8 — broader, evidenced model selection

Prerelease date: 2026-11-02 (Asia/Seoul). npm channel: **`next`**. **1.0.0 remains on hold.**

## Changes

The Skill builds a broad target Claude Code model pool before assigning Agents. It separates eligible, unverified and excluded candidates, compares actual task requirements and the leading alternative, and considers expected total work rather than model age, family or the main conversation's model. Routine extraction, research, writing, implementation, test execution and review are all subject to the same comparison. Older Opus versions are not assumed cheaper.

Ordinary improvement requests also reassess existing model fields. An evidenced model-only correction preserves other instructions, tools, language, metadata and byte formatting; separately stated fixed models and ceilings remain binding. Unknown price does not force inheritance, and unverified alternatives stay outside runnable frontmatter. No automatic routing, retries, model-access probes or routine selection questionnaire is added.

The updater recognizes verified unmodified public alpha.6/7 payloads. Customized Skills still stop for manual comparison/merging, and existing project `.claude/agents` are not changed by install/update. The CLI and static-validator public interfaces are unchanged.

## Install or update

```sh
npx --yes @woody_s/configure-subagents@next install --agent all
npx --yes @woody_s/configure-subagents@next update --agent all
```

Use `install` for a new installation and `update` for an existing selected host. Use `--agent claude` or `--agent codex` for a single host. Pin `@0.1.0-alpha.8` for a reproducible version. Updating the Skill does not itself revise your Agents: invoke the Skill in your selected host to request configuration improvement.

See the [complete bounded evaluation](../evals/MODEL_SELECTION_BEHAVIOR.md). Failed/blocked setup attempts are retained. ## Remaining limits and stable release

The fixture's eligibility, prices, latency and workload qualifications are simulated. No generated Agent was invoked, and no actual performance, savings, quota, account access or runtime model routing is established. Installation is distinct from host discovery and Agent execution.

The earlier [Claude first-pass exception/cross-review limitations](../README.md#known-behavior-limitation-in-alpha5) remain open; this model-selection round does not close them. The [1.0.0 checklist](../docs/V1_RELEASE_CHECKLIST.md) requires the frozen installed RC matrix, repeated high-risk first-apply/repeat checks, host-level failure/concurrent-edit preservation and exact-artifact verification before a separate stable-release decision.

This release updates `next` only. It does not move `latest` or declare 1.0.0.
